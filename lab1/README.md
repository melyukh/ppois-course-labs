## Лабораторная работа 1: Вектор

Класс `Vector` — реализация трёхмерного вещественного вектора.

### Возможности

**Базовые:**
- Хранение координат конца вектора `(x, y, z)`, начало считается точкой `(0, 0, 0)`
- Вычисление длины вектора (`length`)
- Сложение / вычитание (`+`, `+=`, `-`, `-=`)
- Умножение на число (`*`, `*=`)
- Деление на число (`/`, `/=`)
- Векторное произведение (`@`)
- Вычисление косинуса угла между векторами
- Сравнение векторов по длине (`==`, `!=`, `>`, `>=`, `<`, `<=`)

**Сервисные:**
- Инкапсуляция через `property` с валидацией типов координат
- Копирование (`__copy__`)
- Чтение из строки (`generate_from_string`) и из итерируемого объекта (`generate_from_iterable`)
- Сериализация в строку (`__str__`)
- Консольный интерфейс, независимый от реализации класса

### Пример использования

```python
from src.vector.classes.vector import Vector

v1 = Vector(1, 2, 3)
v2 = Vector(4, 5, 6)

v3 = v1 + v2                 # сложение
angle_cos = Vector.cos_between_the_vectors(v1, v2)
cross = v1 @ v2               # векторное произведение
```

## Лабораторная работа 2: Матрица

Иерархия классов для работы с вещественными матрицами произвольного размера.

### Иерархия классов

```
BaseMatrix (ABC)              — структурные операции (1.7.1)
    └── Matrix                — арифметика + фабричный метод (1.7.2)
            └── SquareMatrix          — детерминант, возведение в степень
                    ├── DiagonalMatrix       — O(n) вместо O(n³) для det/mul/pow
                    │       └── IdentityMatrix — O(1) для det/pow/mul
                    ├── SymmetricMatrix
                    ├── HighTriangularMatrix
                    └── LowTriangularMatrix
    └── ZeroMatrix
```

### Возможности

**Базовые (1.7.1):**
- Изменение размера матрицы (`resize`) с сохранением пересекающихся данных
- Загрузка матрицы из файла (`generate_from_file`) и из строки (`generate_from_string`)
- Извлечение подматрицы произвольного размера и смещения (`submatrix`)
- Проверка типа матрицы: квадратная, диагональная, нулевая, единичная, симметрическая, верхне-/нижнетреугольная
- Транспонирование (`transpose`)

**Усложнённые (1.7.2):**
- Сложение / вычитание матриц и чисел (`+`, `+=`, `-`, `-=`)
- Умножение матриц (`*`) и умножение на число (`*`, `*=`)
- Деление матрицы на число (`/`, `/=`)
- Возведение в степень (`**`) — бинарное быстрое возведение, только для квадратных матриц
- Вычисление детерминанта — метод Гаусса, $O(n^3)$
- Вычисление нормы Фробениуса

### Пример использования

```python
from src.matrix.classes.matrix import Matrix

m1 = Matrix.create([[1, 2], [3, 4]])
m2 = Matrix.create([[5, 6], [7, 8]])

result = m1 * m2              # матричное умножение
det = m1.determinant()        # определитель
norm = m1.norm()              # норма Фробениуса
```

### Фабричный метод

`Matrix.create(data)` анализирует переданные данные через методы-предикаты (`is_diagonal()`, `is_identity()` и т.д.) и автоматически возвращает объект наиболее специализированного подходящего подкласса. Это позволяет каждому вычислительному методу использовать оптимальный алгоритм для конкретного типа матрицы без явных проверок со стороны вызывающего кода:

| Тип матрицы       | `determinant()` | `__pow__` | `__mul__` (с тем же типом) |
|-------------------|:---------------:|:---------:|:---------------------------:|
| `SquareMatrix`     | $O(n^3)$ (Гаусс) | $O(\log n \cdot n^3)$ | $O(n^3)$ |
| `DiagonalMatrix`   | $O(n)$           | $O(n)$    | $O(n)$ |
| `IdentityMatrix`   | $O(1)$           | $O(1)$    | $O(1)$ |

## Тестирование

Тесты написаны на `pytest`, используют параметризацию (`@pytest.mark.parametrize`) и `pytest.approx` для сравнения чисел с плавающей точкой.

Запуск всех тестов (из корня `lab1`):

```bash
pytest -v
```

Запуск тестов конкретной лабораторной работы:

```bash
pytest -v src/vector/tests/
pytest -v src/matrix/tests/
```

### Покрытие тестами

- **Vector:** аксиомы сложения/умножения на скаляр (коммутативность, ассоциативность, дистрибутивность, нейтральный/обратный элемент), свойства скалярного и векторного произведений (коммутативность/антикоммутативность, ортогональность, коллинеарность, перпендикулярность результата), граничные случаи (нулевой вектор, деление на ноль), сериализация (round-trip), копирование, сравнение.
- **Matrix:** структурные операции (`resize`, `submatrix`, `transpose`), все проверки типов матриц, полный набор арифметических операций с проверкой размеров и типов, корректность детерминанта (включая случай, требующий перестановки строк, и вырожденные матрицы), неизменность исходной матрицы при вычислении детерминанта, сериализация, фабричный метод (корректность выбора подкласса), копирование.

## Архитектурные решения

- **Отделение интерфейса от реализации.** Консольный UI (`cli_API/`) взаимодействует с классами только через их публичный API (методы, свойства, перегруженные операторы) и не имеет доступа к внутренним деталям реализации.
- **Инкапсуляция.** Внутреннее состояние объектов защищено через `property`/соглашение об именовании (`_` / `__`) с валидацией типов и инвариантов на входе.
- **Наследование и полиморфизм (Matrix).** Общая логика (структурные операции) реализована один раз в `BaseMatrix` и переиспользуется во всей иерархии; специализированные подклассы переопределяют только те методы, где возможна алгоритмическая оптимизация — без изменения кода, который эти методы вызывает.
- **Фабричный метод.** Создание объекта нужного специализированного типа вынесено из конструктора в отдельный `classmethod`, что позволяет автоматически выбирать оптимальную реализацию по свойствам входных данных.
- **Разрешение циклических импортов.** Поскольку фабрика в `Matrix` должна знать обо всех подклассах, а подклассы — о своих родителях, импорты подклассов внутри `create()` выполняются отложенно (внутри метода), что разрывает цикл на уровне загрузки модулей.
- **Копирование объектов.** Реализован `__copy__` с глубоким копированием внутренних списков (поверхностной копии Python недостаточно для `list[list[float]]`).
